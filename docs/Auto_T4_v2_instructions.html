Auto_T4_v2: automatic cell session, one-page guide

REISERLAB-EPHYS, MATLAB R2023a. One command runs everything after break-in, about 46 min (3 min more when the arena is re-aimed). Version of 30 Oct 2026: v1 plus the arena re-aim for receptive fields near the top or bottom of the screen; the re-aim check now scans the whole Protocol 1 area and rejects noise.

Before the first cell of the day (once)

addpath('C:\matlabroot\GitHub\nested_RF_stimulus_reaim\src\protocol_generation')
Auto_T4_v2('JY1030a', 'L', 'check_only', true)

This checks the code, the arena controller, the Host settings (ADC1 and ADC2 at 10 kHz, 3 rows) and the disk space, and runs nothing. It must end with "all checks passed". Type the addpath line before every Auto_T4_v2 call: Auto_T4_v2 takes its folder off the path when it ends. Close the G4 Conductor and any other MATLAB that talks to the arena. Set the swiveling base to 0° (or give its reading, below).

Each cell

  1. Break in. Current clamp, 0 pA.
  2. Start the session with a new cell tag each time. The side is 'L' or 'R'. 
    addpath('C:\matlabroot\GitHub\nested_RF_stimulus_reaim\src\protocol_generation')
Auto_T4_v2('JY1030a', 'L')
  3. A second MATLAB opens the arena viewer. A status window lists the steps (12), the clock times and any FLAG.
  4. After 30 s of dark, MATLAB asks for the holding current: set it on the amplifier, type the value in pA, press Enter. Do not change it after this.
  5. Protocol 1 and its peak run. Only if the peak is near the top or bottom edge, the re-aim prompt comes (green box below). Otherwise nothing is asked.
  6. Then it runs hands-off: Protocol 2 stage 1 (8 min), read-out, stage 2 (3 min, 30 bars), read-out and placement, Prot3b (8 min), Protocol 4 (16 min). At the end the arena goes dark.
Re-aim the arena (only when asked). A box RE-AIM THE ARENA gives the peak, its distance to the edge, the angle to turn the base, for example Rotate the stage by +18.5 deg (from +0 to +18.5), and where the RF should land.
  1. Turn the base by that angle (the range is ±20°; CLAMPED means the full move does not fit). Press Enter, or type s and Enter to skip the re-aim.
  2. Type the angle you actually moved, then Enter (Enter alone = the suggested angle).
  3. An ON scan of the whole Protocol 1 area finds the RF at the new angle (about 1.6 min). A figure then shows the map: gray square = peak before, red × = predicted, circle = found (green GOOD, orange CHECK = on the scan's edge, red = NO RESPONSE). The title gives the mV, the SNR (needs 4) and the ratio to the peak before (needs 0.5).
  4. GOOD or CHECK, choose: Enter = continue (Protocol 2 is aimed at the found peak); c = repeat the scan; a = re-aim again from there (offered when still near the edge); s = stop.
  5. NO RESPONSE (noise only; Protocol 2 is not aimed there), choose: c = repeat the scan; r = turn the base back to the old reading, then the re-aim is asked again; p = turn the base back and go on with the old peak; u = use this peak anyway (a clear peak, only weaker: Protocol 2 is aimed there, flagged); s = stop.
After s with no response: turn the base back to the old reading and resume with 'reaim_reset', true (add 'reaim_sign', -1 if it turned the wrong way). If the base is not at 0 at the start, add 'stage_angle_deg', <reading>.

Abort, resume, lost cell

Stop nowPress Ctrl+C in the MATLAB that runs the session (not the viewer). The display stops, the analog output returns to zero and the logs close. The arena stays on the gray background.
Resume (after Ctrl+C, a FLAG stop, an error or a crash)Type the same two lines again (addpath, then Auto_T4_v2('JY1030a', 'L')). Steps that are done are kept. The interrupted step restarts from its beginning.
Cell lost: close the recordAfter the addpath line: Auto_T4_v2('JY1030a', 'L', 'abandon', true). Start the next cell with a new tag.
Arena dark by handc = PanelsController(); c.open(true); c.allOff(); c.close();
Fallback: the previous version (v1, no re-aim). If v2 fails and cannot be resumed, run the last working version on a new cell tag, two lines (if in doubt, restart MATLAB first): 
addpath('C:\matlabroot\GitHub\nested_RF_stimulus_session_ui\src\protocol_generation')
Auto_T4_v1('JY1030b', 'L')
A session folder is resumed only by the version that started it.

Where the data go

  • Session folder: D:\nested_RF_sessions\<cell tag>, holding one folder per protocol (p1, p1_confirm, p2b, p3b, p4), readout\, plots\, session_log.txt and decisions.json. The re-aim angles are in decisions.json.
  • Protocol 2 stage 1: C:\matlabroot\G4_Protocols\nested_RF_protocol2\data\<date_time>.
  • Other folders: 'root','E:\JY_data', 'p2_package_root', .... Give the same 'root' when you resume.

If something stops

  • FLAG lines: an automatic decision fell back. The session continues unless the line says it stopped.
  • No Protocol 1 peak (below 2 mV): the session stops. To aim by hand, resume with 'peak_frame', 239.
  • Ctrl+C mid-protocol re-runs that whole protocol on resume. If you can, stop between protocols.
  • Arena, Host or amplifier acting strangely: Ctrl+C, note the time, tell Michael.
