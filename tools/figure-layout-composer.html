Figure Layout Composer — Help

Quick Start: Step-by-Step

1
Pick your journal. Select from the Journal dropdown in the sidebar. This auto-sets canvas width, label formatting (uppercase vs lowercase, size), font sizes, and shows a constraint banner with that journal's requirements.
2
Choose column width. Click the column-width buttons (1-col, 1.5-col, Full) below the journal dropdown. The canvas resizes to match. A dashed red line shows the journal's max figure height.
3
Add panels. Either click Panel in the toolbar to add an empty panel, or drag-and-drop PNG files directly onto the white canvas. PNGs are just rough previews — the final figure will be generated as a vector PDF by Claude.
4
Arrange your layout. Drag panels to reposition. Resize by dragging the blue corner/edge handles. Use Shift+click to multi-select, then use the alignment buttons (top toolbar) to align edges or distribute spacing evenly.
5
Describe each panel. Click a panel to select it, then in the sidebar: set its Type (Plot = Claude generates plotting code; Image = static file embedded directly) and write a Description of what it shows (e.g., “polar tuning curve, 28 dps bar sweeps, ON-control cells”). This is the key info Claude uses.
6
Add notes. Click Panel Note to attach an instruction to the selected panel (shown in yellow, e.g., “increase line weight”). Click Global Note for figure-wide instructions (shown in blue, e.g., “use same y-axis for a–c”). Double-click any note to edit.
7
Copy the spec. The Export section at the bottom of the sidebar shows a live-updating specification. Click Copy Spec, paste it into Claude, and Claude will write MATLAB or Python code that produces the final vector PDF figure.
The workflow is iterative: adjust the layout, re-copy the spec, paste into Claude, and Claude updates the code. PNGs are throwaway previews — the final output is always code that generates an editable vector PDF.

Layout Tools

  • Preset layouts: Use the Layout Presets section in the sidebar for quick starting points (2 side-by-side, 2×2 grid, 3×2 grid, 1 wide + 2 below).
  • Alignment: Select 2+ panels with Shift+click, then use the align buttons: ▌ ┃ ▐ (left, center, right) and ▀ ━ ▄ (top, center, bottom).
  • Distribute: With 3+ panels selected, Dist H / Dist V equalizes the gaps between them.
  • Match size: With 2+ panels selected, W / H makes all panels match the first panel's width or height.
  • Margin & Gutter: Set global outer margin and inter-panel gap in the Grid & Snap section. These values are used by preset layouts and the distribute tool.
  • Snap to grid: Enabled by default (0.25″ steps). Toggle off in sidebar or hold Shift while arrow-nudging for fine 0.01″ steps.

Panel Properties

  • Type: Plot = Claude generates the plotting code from your data. Image = a static file (microscopy, schematic, diagram) that Claude embeds directly.
  • Description: Free text. Be specific about what data to plot, which cells/conditions, aggregation method (e.g., “median±MAD”). The more detail, the better Claude's first pass.
  • Lock aspect ratio: When checked, resizing preserves the panel's proportions. Auto-set to the image's native ratio when you load a preview PNG.
  • Replace Image: Load a different preview PNG into the selected panel.

Journal Presets

Each journal preset auto-configures:

SettingWhat it controls
Canvas widthColumn widths per journal spec (in inches)
Max height lineRed dashed line at journal's max figure height
Label styleFont size, bold/regular, uppercase/lowercase (Nature uses 8pt bold lowercase; Cell uses 7pt bold UPPERCASE)
Font sizesAxis labels, tick labels, title — set to journal's recommended range
Constraint bannerShows min line weight, DPI, color mode, special rules
You can override any auto-configured value after selecting a preset. The preset just gives you a fast starting point.

Output & Workflow

The exported spec includes:

  • Canvas dimensions — exact size in inches
  • Panel positions & sizes — in inches, for precise placement
  • Panel types & descriptions — tells Claude what code to write per panel
  • Annotations — panel-specific and global instructions
  • Font spec — family, sizes for labels/axes/ticks/titles
  • Journal constraints — min line weight, DPI, color mode, colorblind-safe flag

Toggle MATLAB / Python in the Output section of the sidebar to change the prompt language. Claude will generate the corresponding code (tiledlayout for MATLAB, gridspec for Python).

Tips

  • Start with a layout preset, then drag your PNGs onto each panel to replace the placeholders.
  • Use the zoom slider to get a better view of large figures or fine details.
  • Panel descriptions are the most important field — be specific about data source, cell type, conditions, and plot style.
  • Use Global Notes for instructions that span multiple panels (shared axes, color schemes, etc.).
  • The spec updates live as you make changes — no need to click “generate”.
